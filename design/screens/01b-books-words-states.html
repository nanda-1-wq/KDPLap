Rule 1 (owner, Q1): for each section, the words of its current version now, minus the words of its newest version from before the 1st (UTC). A section never counts below 0, so a cut does not subtract. A section started this month counts all its words. The value comes from one server call (words_month, 0026), loaded with the AI usage card. The usage card shows a skeleton the same way. An error never blocks the books: the card shows "–", as the usage card does. The month label is the UTC month, the same as the usage card ("Resets Nov 1").
