Export states

Export builds the file in the browser from each section's current saved version, in outline order. Unsaved edits are never in the file. Open "Verify: no source" marks never leave silently: the dialog lists them and asks for a tick. In the file the marks are removed and the sentence stays. Page size comes from the Brief; Export only reads it. The dialog is 600 px wide; on short screens its body scrolls and the footer stays.
