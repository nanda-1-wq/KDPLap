E12 fix batch 3 · items 3, 4 and 5 · 06 Write and the book shell

Mark all as reviewed, Mark book as completed, Checks rows

Three additions to 06 Write. A "Needs review" mark can be cleared for a whole chapter or the whole book at once. The book can be marked completed when every section is Final. The Checks tab gets two info rows. These rows never count and never block "Ready to mark Final".

A · Item 4

Mark all as reviewed

The same rule as the section's own "Mark as reviewed" (fix batch 2, item 4). It clears the "Needs review" mark, and the status stays. One save for all the sections, then a count you can trust.

B · Item 3

Mark book as completed, and Reopen

The rule: the outline is approved, every section is Final and has text, and nothing needs review. A completed book stays editable (owner, Q3 B). It reopens on its own only when the rule breaks: a section leaves Final, a section or chapter gets "Needs review", a section or chapter is added, or the outline approval is cleared. A new version on a Final section keeps it completed (owner, D1).
