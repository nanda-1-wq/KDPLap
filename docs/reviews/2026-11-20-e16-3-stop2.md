## 5 · A note on "sharp" (no change proposed)
"Natural size" is in CSS pixels. On a 2× screen (a Retina Mac), a 640 px file drawn at 640 CSS px uses 1 file pixel for 2 × 2 screen pixels. So it is a little softer there than the old 1,280 px file, which got about 1.35 screen pixels per file pixel (1,280 px drawn at 864 CSS px). It is never blurred by an upscale beyond that. Showing it at 320 CSS px for 1:1 on Retina would make it too small. My recommendation: keep it as built (Q2 as answered).
