## 1. What Part 1 built

11 pure files in `js/cover/` (no DOM, no network; the repo's IIFE on `globalThis.kdpCover` pattern; 1,326 lines). Load order: `js/format-rules.js`, then geo, textlayout, shapes, names, model, remap, history, palettes, kindle, checks, layouts.

| File | What |
|---|---|
| `geo.js` | `geo(fmt)` field for field as the design; 6 trims; the spine per page read from 08's `kdpFormatRules.SPINE_PER_PAGE` (one source of truth, not rounded, as the design); align regions; distortion corners and the homography (the design's `quadMatrix` as numbers). |
| `textlayout.js` | The one line breaker (plan §1): CSS rules of the finals (line height 1.15, letter spacing, pre-wrap, break-word, capitals). `setMeasure()` takes `ctx.measureText` in Part 4. | `model.js` | The design's layer factories and defaults; new text, book text and picture; cover fit, crop clamp, DPI; boxes on rotated layers; arrange (jumps past the next real overlap), duplicate, align, distribute, nudge, select all; size steps; `normalize()` (defaults, unknown fields dropped, ranges clamped to the design's controls); the caps (200 layers, 2,000 characters, 512 KB). |
| `remap.js` | The design's `remap()` unchanged; `changeFormat()` (the `last_remap` data); the F72 note words. |
| `history.js` | 50 steps, the sliding 500 ms window, a drag is one step, `{layers, bg}` only, an injected clock. |
| `checks.js` | The 14 rules with the design's words and thresholds, on rotated boxes, skipping hidden and excluded layers; the chip. |
| `layouts.js` | 12 ready layouts + Blank (the design's literals), Add spine text, My layouts on a new book. |
| `palettes.js` | 6 series palettes (`swapPalette`), luminance and contrast, HSV, the picker's CMYK read-out, recent colors. |
| `kindle.js` | The 1600 × 2560 plan: cut at the trim to 1 : 1.6, or kFit for wide trims; the preview transforms. |
| `shapes.js` | 27 paths (the design's `shapePath()`, string-equal), new-shape fields, kind swap, an SVG path parser (absolute, relative, packed arc flags), arcs to cubics, SVG to Typst `curve` (straight closes; even-odd in Part 2). |
| `names.js` | Layer names, file names (`<slug>_<trim>_<pages>p_<paper>_cover.pdf` …), the size labels, the Kindle and spine lines. |

**How the numbers are proved.** The design's own logic is the oracle:
- `tools/cover-golden.mjs` runs the design's `<script>` class headless in Deno, with a stub for the design canvas base class. It never reads `js/cover`.
- It freezes the design's answers into `tests/fixtures/cover-golden.json` (598 KB, 4 decimals).
- `tests/cover-golden.test.js` checks that the frozen file still equals a fresh run of the design.

Each case runs twice:
- **Port proof:** the built code with the design's own text-height estimate. Every number and every check message must equal the design.
- **Built:** the built code with `kdpCover.textlayout` (stub widths). The 288 layouts must have no error and no warning, and every Blank exactly the 3 "missing" Must fix items.

## 6. New, your call

**N1. 7 pt Plex capitals do not fit at 84 and 85 pages on white.**
- The thresholds 80 cream / 84 white come from E15's Source Sans 3 (cap 0.66). IBM Plex Sans has cap 0.698.
- At 84 white the room is 0.0642 in and 7 pt capitals need 0.0679 in: 0.0037 in too little (0.0014 in at 85).

  - (a) keep it as is;
  - (b) **rec:** spine text on white from 86 pages (one number; cream stays 80), so the app never offers spine text that its own check rejects;
  - (c) keep 84 and use a spine font with lower capitals by default.

**N2. Spine words.** The full title plus the pen name (D2 "this book's title"), rather than the design's 3-word short title. **Rec:** full title (KDP checks that the spine matches the book), with N3 for long titles.
