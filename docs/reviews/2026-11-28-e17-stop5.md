## My choices (please confirm)
- A. Print order: ticked app books first, then typed books, each in its own order. The arrows move a book only inside its group. One list across both groups would need arrows that move rows between sections.
- B. Typed books: Remove only, no Edit (difference 7).
- C. "Replace text" is the ink primary button, as drawn in 80b (not red). The task text said "secondary style"; I read it as "not destructive".
- D. First open copies the bio only when there is no version AND no draft (typed text is never replaced without the dialog).
- E. Copy again with an empty editor asks nothing.
- F. Ticks that are no longer valid (the pen name changed) are hidden but kept in the list, so they come back if the pen name changes back.
