## Things found on the way

1. **Wording after a status change.** Marking a section Final in 06 moves `qc_inputs_key` only, so 55 B
   says "Your outline, Brief, Research or 08 settings changed". That is the plan's copy and it is not
   wrong enough to change alone, but a status change is probably the most common reason for this
   message. Suggested: add "or a section's status". Owner's call.
2. **`results.sources` has no place on screen.** The run saves which sources were named and where. Design
   53 shows only a count and a note, so the names are saved and never shown. Built as designed.
3. **Plan row moved.** Two small `js/book-write.js` changes are here, not in E14.4: a draft save tells
   the shell it was only a draft (`ctx.refresh({ draft: true })`), and `pickSection` opens the section
   for Open in 06. Steps 4 and 5 need them.
4. **06 Next** is on now, so one line of `tests/browser/write/t1.js` changed on purpose ("Next is off on
   the last v1 step" is now "Next is on: 06 goes to 07").
