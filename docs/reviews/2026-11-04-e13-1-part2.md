## Worker result (option A, owner conditions)
| Check | Result |
|---|---|
| Chrome, 164-page book in the worker | 638 ms, main thread blocked at most **12 ms**; Typst conversion 5 ms |
| Chrome, forced fallback (test-only flag), 52 pages | main thread, same sha384 and pages as the worker PDF; 412 ms, page blocked 28 ms |
| Rule 1: crash → worker ended, new one started | 1 crash, 2 worker starts; the new worker builds (same bytes) |
| Rule 2: by the error, not the browser | overflow in the PDF step falls back; a Typst error and an overflow in another step do not |
| Rule 3: per book, for the session | next build straight to the main thread (no worker try); still so after a reload; other books stay in the worker |
| Rule 4: delay and paint | preview delay 1,500 ms (main) / 600 ms (worker); order "Updating preview" → frame → compile |

## Drop cap
droplet 0.3.1 works on Typst 0.14.2 as is (no simpler option needed). Three lines high,
on the chapter's first paragraph (after the first section title); a chapter that starts
with a list or a heading gets none. Typst does not indent a paragraph after a block, so
the paragraph after the drop cap is wrapped in `after-drop` (the 0.25 in indent).
