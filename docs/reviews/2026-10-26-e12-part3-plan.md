### The exact phrases for 2b
These are matched case-insensitively as whole words, with any spaces between the words. Headings are not checked; paragraphs and list items are.

| Phrase | Matches | Example |
|---|---|---|
| `next section` | also "the next section" | "The next section shows you how…" |
| `next chapter` | | "In the next chapter, you will…" |
| `following section` | also "in the following section" | "In the following section, we…" |
| `following chapter` | | "The following chapter covers…" |
| `later in this book`, `later in the book` | | "You will learn more later in this book." |
| `later in this chapter` | | "We come back to this later in this chapter." |
| `section` + a number | "section 3.1", "Section 2" | "In section 3.1, you met four quick practices." |
| `chapter` + a number | "chapter 4", "Chapter 5.2" | "Chapter 5.2 will show you…" |

**Not flagged** (back references are allowed; the M3 and M8 rules ask for them): "earlier in this book", "earlier in this chapter", "the next step", "the next morning", "the following steps", "a section of the routine", "this chapter". A plural ("the next sections") is not matched. Say if you want any phrase added or dropped.
