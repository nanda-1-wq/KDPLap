## Choices to check

1. **A failure pauses the run.** Try again goes on from that chapter through the rest, with no new confirm. Close ends it.
2. **Stop stays stopped.** If the chapter in flight fails after Stop, 55 D does not show. The result shows, with Check again on that chapter.
3. **A chapter that changed after the confirm** (too short, too long, no text, removed) costs nothing, so it is skipped and the run goes on, with no error shown. The chapter shows its true state after a fresh read.
4. **Cancel holds the first focus in 54 A,** so Enter never pays by accident.
5. **No room left disables the button** (as Generate chapter does). A failed usage read does not: the server still has the limit.
6. **After a lost connection with a failed read, Try again sends nothing** until a read works. If the read shows the chapter saved, it counts as done and the run moves to the next one. If that was the last, the result shows with no failure.
7. **Marked drifts still count against N of M.** N is what the AI said, not what the writer accepted.
