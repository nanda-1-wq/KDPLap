## Section-id seams given a target type (risk P1)

`cur.type` is 'section' or 'part'. `T(type)` routes text, head, versions, version, saveDraft,
saveVersion and restore.
- Autosave: read, save, onSaved, onError (fixed parts never autosave; the epigraph is capped at 1,000).
- openTarget (replaces openSection; openSection stays as a wrapper).
- loadVersions, makeVersion (adds the part_too_long note), restore.
- adoptRemote, checkRemote, resolveConflict.
- setStatus → setPartStatus for parts (book_parts.status).
- Compare: reads the version through `T(cur.type).version`.
- Improve: request (stage part_improve with partId), accept (apply_part_suggestion), applyFailed
  (re-reads the part text).
- Notes, loading text and errors use noun() ("section" or "book part").
- URL: `?part=` with `query()`; `sectionQuery`.
- openSpot, Generate, Checks and the QC bar get `sec()`, which is null for a part. To them a part
  looks like "nothing open".
- moveTo / selectSection take a type; moveToSection stays.
