### The CDN switch (`js/format/typst-run.js`)
Once jsdelivr fails both tries of one file with no answer or an HTTP error (not a wrong file),
later downloads in that worker or page go to unpkg first, then jsdelivr, with no 1 s wait.
Every file still has two servers. It lasts until a reload. The engine reports it with
`kdpTypstRun.unpkgFirst()`.

**Finding:** the plan expected this to cut the 19.6 s "jsdelivr down" time. It does not, for the
first visit: the 6 first files start together, so their 1 s retry waits run side by side, and
most of that time is unpkg's own cold download. The switch helps every download after the
first batch: a style change, pdf.js in Part 3. Measured below.
